# Word Image Negative

Простая и эффективная надстройка (плагин) для **Microsoft Word**, которая позволяет в один клик инвертировать цвета (накладывать эффект негатива) на выбранное в документе изображение. Проект разработан на языке **C#** с использованием технологии **VSTO**.

---

## Возможности
* **Мгновенная обработка**: Инверсия цветов реализована через `ColorMatrix` (.NET), что обеспечивает высокую скорость работы даже с большими изображениями.
* **Работа без сохранения на диск**: Картинка считывается, обрабатывается в оперативной памяти и заменяется прямо внутри открытого документа Word.

---

## стек
* **Язык программирования:** C#
* **Платформа:** .NET Framework 4.7.2+
* **Технология Office:** VSTO (Visual Studio Tools for Office)
* **API взаимодействия:** Microsoft.Office.Interop.Word

## 

### Шаги для запуска:
1. Клонируйте этот репозиторий себе на компьютер:
   ```bash
   git clone https://github.com/BagleR67/MSWord-Invert-Pic
   ```
2. Откройте файл `.sln` в Visual Studio.
3. Убедитесь, что в вашей Visual Studio установлен компонент **«Разработка надстроек Office/SharePoint»**
4. Полностью закройте Microsoft Word на вашем компьютере.
5. В Visual Studio нажмите запуск проекта (или f5)

---

## как использовать?
1. В открывшемся документе Word перейдите на вкладку **«Надстройки»**
2. Вставьте или найдите любое изображение в тексте.
3. **Выделите картинку мышкой** (так, чтобы вокруг неё появились маркеры изменения размера).
4. Нажмите кнопку на панели плагина. Цвет картинки мгновенно инвертируется.
